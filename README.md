# Going, Going, Gone! Calculator

A static calculator for the "Going, Going, Gone!" auction mode (Gold Shells).

- **Appraise**: enter each lot's low/high value (accepts `12k`, `1.5m`), plus total-value intel bounds.
- **Bid helper**: pick the round (R1 >2x, R2 >1.6x, R3 >1.3x, R4 >1.1x the 2nd-highest bid; R5 highest wins), enter opponents' bids, and see the minimum instant-win bid and its profit range. Also checks your own bid and the 10% loss bonus.
- **Catalog**: all 227 collectibles from the in-game Collectibles Index (name, rarity, size, price), with silhouette lookup and slot-count solver.
- **Settlement**: profit/loss for the winner and the 10% bonus each other player gets when the winner loses.

Open `index.html` in a browser, or enable GitHub Pages on this branch. `src/app.html` is the same page without the document wrapper.
